# Retired documents

These are kept for reference and are **no longer maintained**. They are excluded
from the bilingual parity check (`tools/check_docs_parity.py`), so they will drift
from the code — read the live English originals instead.

| Here | Read this instead |
|---|---|
| `DISENO.md` | [DESIGN.md](../DESIGN.md) |
| `MANUAL_ES.md` | [MANUAL.md](../MANUAL.md) |

**Why they were retired (2026-07-27).** Keeping four documents in two languages had
cost **51 % of all documentation effort on the project** (3,167 line-edits on the
Spanish side vs 3,052 on the English one), maintained by one person. These two
serve the maintainer and the CLI-reference reader — an audience that reads English
by default. The two that stay in Spanish are the ones where it earns its keep:
[LEAME.md](../LEAME.md), the front door for a Spanish-speaking visitor, and
[GUIA.md](../GUIA.md), whose whole audience is the non-ceremonious developer the
tool is built for.
